# Mac Apps Beta

집중을 돕는 **FocusShade**와 메뉴 막대를 정리하는 **MenuFold**의 배포용 저장소입니다.

현재 버전: **0.0.1 · 베타**

[다운로드](https://github.com/inspire12/mac-apps/releases/tag/v0.0.1) · [패치노트](CHANGELOG.md) · [문제 제보](https://github.com/inspire12/mac-apps/issues)

## 설치

Apple Silicon(M1 이후), macOS 13 이상이 필요합니다. Intel Mac은 지원하지 않습니다.

1. Releases에서 필요한 앱의 DMG 또는 두 앱이 포함된 ZIP을 다운로드합니다.
2. DMG를 열고 앱을 Applications로 드래그합니다.
3. DMG를 추출하고 응용 프로그램 폴더에서 실행합니다.
4. 개발자를 확인할 수 없다는 경고가 나오면 신뢰하는 배포 파일인지 확인한 후 시스템 설정 → 개인정보 보호 및 보안 → ‘그래도 열기’를 선택합니다.

Apple 공증을 받지 않은 베타입니다. ‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’ 경고는 우회하지 말고 제보해 주세요. [Apple 공식 안내](https://support.apple.com/ko-kr/102445)

## 문제 제보

Issues에 앱 이름과 버전, Mac 칩, macOS 버전, 재현 순서 및 실제 동작을 적어주세요. 화면이나 로그를 첨부할 때 개인정보를 지워주세요.

이 저장소에는 배포 안내와 패치노트만 포함합니다. 앱 소스 코드는 포함하지 않습니다.
